The admin needs a Supabase project. Until it is set up, nobody can sign in and no car can be added here.

  1. Create a free project at supabase.com. Pick the region closest to Uganda.
  2. In the SQL Editor, run supabase/schema.sql from the repo.
  3. Under Authentication, turn off public sign-ups, then add each admin's email and password.
  4. Add each admin to the admins table (the last lines of schema.sql show how).
  5. Copy the Project URL and the anon public key into src/data/site.json, then rebuild.
